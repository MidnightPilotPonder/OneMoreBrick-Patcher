**OneMoreBrick‑Patcher** is a lightweight Windows‑only utility that adjusts the original *One More Brick* game files so they run smoothly on Windows 10/11. It adds compatibility tweaks, resolves known bugs, and provides a simple one‑click fix for the most common issues reported by players.

---

## 🎯 Who should use this?

- **Windows 10 / Windows 11 gamers** who own a copy of *One More Brick*
- Anyone experiencing crashes, missing textures, or controller glitches on modern Windows builds
- Players looking for a hassle‑free way to keep their game up‑to‑date without manual file edits

> **Note:** This utility is designed exclusively for desktop Windows environments. It is **not** compatible with macOS, Linux, or older Windows versions.

---

## 🛠️ How to Use

1. **Run the utility** – double‑click the downloaded file.
2. **Select your game folder** – the utility will auto‑suggest the most likely location; you can browse manually if needed.
3. Click **“Apply All Patches”**.
4. Wait for the progress bar to complete (usually under 30 seconds).
5. Launch *One More Brick* and enjoy the smoother experience!

A short **log.txt** file will be created beside the game executable, summarising the changes applied.

## 📂 File Structure (after patch)

```
OneMoreBrick/
├─ Data/
│  ├─ textures.pak   ← refreshed texture pack
│  └─ audio.pak       ← fixed audio cues
├─ Config/
│  └─   ← new settings for Windows 10/11
├─ Release   ← original launcher (unchanged)
└─ patch_log.txt      ← generated by OneMoreBrick‑Patcher
```

## 🐞 Known Limitations

- The patch does **not** modify DRM or copy‑protection mechanisms.
- If the game was installed in a non‑standard directory with restricted permissions, you may need to run the utility as **Administrator**.
